Zorg, új C + + és Java ZRTP kivitelezés nyilvánosságra hozni

Hi all, ma PrivateWave Italia SpA olasz vállalat, a fejlődő technológiák magánélet védelme és az információs biztonság hangon távközlési hol vagyok CTO, akkor engedje Zorg egy új, nyílt forráskódú ZRTP protokoll implementáció letölthető http://www. zrtp.org .

ZRTP [1] előírja end-to-end kulcs csere Elliptic Curve Diffie-Hellmann 384bit és az AES-256 titkosítást SRTP.

Zorg került eredetileg kifejlesztett és megvalósított PrivateWave a PrivateGSM hangja titkosító termékek elérhető az alábbi platformokon: Blackberry, Nokia és iOS (iPhone).

Zorg C + + már integrált PJSIP nyílt forráskódú VoIP SDK [2], és ez biztosított az integráció javítást az PJSIP 1.8.5. Azt vizsgálták, iPhone, Symbian, Windows, Linux és Mac OS X

Zorg Java lett integrálva az egyéni változata MJSIP [3] nyílt SDK a BlackBerry platform, és ez magában foglalja a memória használat optimalizálási csökkentéséhez szükséges minimális szemétgyűjtő tevékenységet.

Mindkét platformok külön és moduláris kriptográfiai hátsó vége, hogy a titkosítási algoritmusok megvalósítása is könnyen cserélhetők más is.

. Zorg licenc alatt GNU AGPL és forráskód elérhető a GitHub a https://github.com/privatewave/ZORG .

Vagyunk felszabadító alatt nyílt forráskódú és a koherencia a mi biztonsági megközelítése [4] azt nagyon remélem, hogy hasznos lehet a nyílt forráskódú ökoszisztéma, hogy új hang titkosítási rendszerek támogatása a szólásszabadság.

Több mint 20 pjsip alapú nyílt forráskódú VoIP titkosító szoftver és számos Java-ban írt részesült közvetlenül a Zorg kiadás.

Örömmel vennénk, hogy megkapja javaslatára együttműködés új integráció, új kriptográfiai hátsó végén, hiba felderítés és bármi hasznos, hogy javítsa, és hagyja ZRTP megerősítik a hang titkosítási szabvány.

Zorg elérhető http://www.zrtp.org .

[1] ZRTP: http://en.wikipedia.org/wiki/ZRTP
[2] PJSIP: http://www.pjsip.org
[3] MJSIP: http://www.mjsip.org
[4] Biztonsági megközelítés: http://www.privatewave.com/security/approch.html
