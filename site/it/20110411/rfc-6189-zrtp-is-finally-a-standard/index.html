RFC 6189: ZRTP è finalmente uno standard!

Infine ZRTP è stato assegnato un incarico ufficiale RFC, RFC6189 ZRTP: Accordo percorso Media Key per Secure RTP Unicast.

Aveva come una dipendenza del SRTP con dimensioni chiave AES 256bit di che ora è stata definita come RFC6188 .

E 'emozionante vedere la RFC finalmente rilasciato, in quanto si tratta di un importante traguardo per impostare ZRTP come standard ufficiale per end-to-end molto simile a PGP è stato per e-mail.

Ora, qualsiasi organizzazione in tutto il mondo sarà ufficialmente in grado di implementare ZRTP per end-to-end di crittografia del protocollo vocale

Attualmente tre diverse implementazioni pubbliche di protocollo ZRTP esiste:

  • Philip Zimmermann LibZRTP (codice C)
  • PrivateWave di ZORG (codice C + + / Java code)
  • GNU Telefonia ZRTP (codice C + + / Java code)

Ciascuno di essi forniscono diverse caratteristiche del protocollo, ma più importanti sono noti per essere interoperabili.

Una nuova ondata sta per il mondiale di cifratura voce, irrupting in una zona grigia in cui la maggior parte delle aziende che fanno sistemi di cifratura di telefono è stato implementazione della crittografia personalizzata.

Ora, una norma è stata impostata e vi sono ragioni limitato ad attuare qualcosa di diverso.

Hurra Mr. Zimmermann e tutta la comunità di aziende (come PrivateWave ) e individui (come Werner Dittmann ) che hanno lavorato su di essa!

Oggi è un grande giorno, questo tipo di tecnologia è ormai ufficiale e anche con più implementazione esistente!
