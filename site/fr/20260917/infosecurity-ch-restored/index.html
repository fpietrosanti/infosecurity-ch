infosecurity.ch est de nouveau en ligne : le blog a été restauré

Après des années hors ligne, infosecurity.ch est de retour. Le 17 septembre 2026, j'ai restauré ce blog à partir de sa copie sur Internet Archive et je l'ai republié sous forme de site statique à l'adresse https://infosecurity.ch.

Tout est comme avant : les articles que j'ai écrits entre 2007 et 2017 sur la vie privée, la sécurité, le hacking, le chiffrement, les interceptions et le renseignement, les commentaires, les tags et catégories, ainsi que chaque URL d'origine, y compris les traductions automatiques de l'époque. Il s'agit d'une archive historique : les commentaires sont fermés et rien n'a été réécrit, si bien que certains liens renvoient vers un web qui n'existe plus.

Ce qui a changé se trouve sous le capot : HTTPS, un sitemap à jour avec les versions linguistiques, des données structurées, un flux RSS et des versions lisibles par machine des articles pour les moteurs de recherche et les assistants IA (llms.txt).
