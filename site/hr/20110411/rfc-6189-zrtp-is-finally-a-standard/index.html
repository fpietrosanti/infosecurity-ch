RFC 6189: ZRTP je napokon standardni!

Konačno ZRTP je dodijeljen službeni RFC zadatak, RFC6189 ZRTP: Mediji Put ključni sporazum za Unicast Secure RTP.

To je kao ovisnost SRTP s AES ključ veličine 256bit koja je sada definirana kao RFC6188 .

To je uzbudljivo vidjeti RFC konačno objavio, kao što je važan korak za postavljanje ZRTP kao službeni standard za end-to-end enkripcije nalik PGP je za e-poštu.

Sada svaka organizacija u svijetu službeno će biti u stanju provesti ZRTP za end-to-end enkripcije protokola glasa

Trenutno 3 različite javne implementacije ZRTP protokol postoji:

  • Philip Zimmermann je LibZRTP (c code)
  • PrivateWave je Zorga (c + + kod / Java kod)
  • GNU Telefonija ZRTP (c + + kod / Java kod)

Svaki od njih pruža različite mogućnosti protokola, ali najvažniji su poznati za interoperabilnosti.

Novi val dolazi na svijet glasovne enkripcije, irrupting u sivoj zoni gdje je većina tvrtki rade telefonske sustave šifriranja provodi običaj enkripciju.

Sada standardni je postava, a ne postoje razlozi lijevo provedbi nešto drugačije.

HURRA g. Zimmermann i sva zajednica tvrtki (kao što su PrivateWave ) i pojedinci (poput Wernera Dittmann ) koji su radili na njemu!

Danas je veliki dan, takva vrsta tehnologije je sada službeno, a također s multiplom postojeće provedbu!

Philip, što je to učinio opet, moje komplimente za svoj čistog duha i odlučnosti :-)
