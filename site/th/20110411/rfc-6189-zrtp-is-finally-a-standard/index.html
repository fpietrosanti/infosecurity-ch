RFC 6189: ZRTP เป็นที่สุดมาตรฐาน!

ในที่สุด ZRTP ได้รับมอบหมายอย่างเป็นทางการที่ได้รับมอบหมาย RFC, RFC6189 ZRTP สื่อข้อตกลงสำคัญเส้นทางการสำหรับการรักษาความปลอดภัยแบบ Unicast RTP

มันมีเป็นพึ่งพา SRTP ที่มีขนาดคีย์ AES 256bit จากที่ตอนนี้ได้รับการกำหนดให้เป็น RFC6188 .

มันน่าตื่นเต้นที่ดู RFC ปล่อยออกมาเป็นมันเป็นก้าวสำคัญที่จะกำหนดเป็นมาตรฐาน ZRTP อย่างเป็นทางการสำหรับการเข้ารหัสแบบ end-to-end มากเช่น PGP ได้รับสำหรับอีเมล

ตอนนี้องค์กรใด ๆ ในโลกอย่างเป็นทางการจะสามารถใช้สำหรับการสิ้นสุด ZRTP-to-end โปรโตคอลการเข้ารหัสเสียง

ปัจจุบันการใช้งานสาธารณะ 3 แตกต่างกันของโพรโทคอ ZRTP อยู่:

  • ฟิลิป Zimmermann ของ LibZRTP (รหัส c)
  • PrivateWave ของ Zorg (C + + รหัส / code Java)
  • GNU โทรศัพท์ ZRTP (C + + / code Java code)

แต่ละของพวกเขามีคุณสมบัติที่แตกต่างกันของโปรโตคอล แต่ที่สำคัญที่สุดเป็นที่รู้จักกันเป็น interoperable

คลื่นลูกใหม่ที่กำลังจะมาถึงโลกเข้ารหัสเสียง irrupting เข้าไปในพื้นที่สีเทาที่ส่วนใหญ่ของ บริษัท ทำระบบการเข้ารหัสโทรศัพท์ที่ได้รับการดำเนินการที่กำหนดเองการเข้ารหัส

ขณะนี้มาตรฐานที่ได้รับการติดตั้งและมีเหตุผลไม่กี่ซ้ายไปดำเนินการบางสิ่งบางอย่างที่แตกต่างกัน

Hurra นาย ซิมเมอ และชุมชนของ บริษัท (เช่น PrivateWave ) และบุคคล (เช่น แวร์เนอร์ Dittmann ) ที่ทำงานกับมัน!

วันนี้มันเป็นวันที่ยิ่งใหญ่ชนิดเช่นเทคโนโลยีคือตอนนี้อย่างเป็นทางการและยังมีการดำเนินการตามที่มีอยู่หลายคน!
