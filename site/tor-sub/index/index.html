This is a tor2web node running on http://tor.infosecurity.ch, node for Privacy Research.

You can access a hidden service tor website with syntax http://hiddenservicename.tor.infosecurity.ch .

It use TOR2WEB.org website configuration templates, please check tor2web website for security and usage instruction.


Please note that this site is not SSL protected!

You can also access any TOR hidden service by typing hidden website hostname (without .onion tld) after http://x.tor.infosecurity.ch.

For example to access to duskgytldkxiuqc6.onion you can go to http://x.tor.infosecurity.ch/duskgytldkxiuqc6.
