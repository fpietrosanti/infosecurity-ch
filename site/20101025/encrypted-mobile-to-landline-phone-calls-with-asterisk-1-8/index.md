# Encrypted mobile to landline phone calls with Asterisk 1.8

We just released a technical howto on [how to build up Secured mobile to landline VoIP infrastructure](http://www.venturevoip.com/news.php?rssid=2464) with:

- [Asterisk 1.8](http://www.asterisk.org/) (just released, support SIP/TLS + SDES key exchange for SRTP)
- [PrivateGSM Enterprise](http://www.privatewave.com/security/security-protocols/srtp-sdes.html) (Nokia / iPhone / Blackberry)
- [SNOM 300 Desktop phone](http://www.snom.com/)

In next weeks others howto like this one will come out by using other server platforms such as FreeSWITCH, all in the spirit of transparency and leverage of opensource security technologies.
